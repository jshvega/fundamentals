## What is it
Basic Vanilla JS calculator built for my FUNDAMENTALS project. No AI.

## What I learned
I learned why storing user input as a string rather than a number matters for sequential character appending. Also, I understood how a class constructor can accept DOM references to decouple logic from DOM queries.

## One challenge I faced
Honeslty, it's been a while since I've built a JS class. So, I struggled a bit with relearning its concept, building one, and then using its methods outside of it. Again, it was just a matter of understanding the concept of it.

## What I'd do differently
My first approach was to build the calculator TOTALLY from scratch, which led to me spending hours building a state model that I didn't even use. In the end I just studied and learned form existing similar projects on YT instead of trying to reinvent the wheel, which is not always necessary/efficient.
